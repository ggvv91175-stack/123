# Checklist — 校园版咸鱼 实施验证清单

> 检查项与 `spec.md` 章节及 `tasks.md` 任务编号一一对应，验收时逐项勾选。

## A. 系统架构设计与技术选型（Task 1，spec 第 6 节）
- [ ] 架构设计文档（docs/architecture.md）存在：含架构图、模块划分（用户认证/商品/求购/互动/订单/平台管理/AI 审核）、部署拓扑
- [ ] 前后端分离 + RESTful `/api/v1`；后端 Controller-Service-Mapper 分层清晰
- [ ] 技术选型确认：后端框架/ORM/MySQL 8/Redis/JWT/bcrypt；前端 Vue 3 + Vant 4（移动端 H5）；部署 Nginx + Docker（或评审确认的等价方案）
- [ ] 选型覆盖非功能性需求：500 并发/P95 800ms、HTTPS+JWT、H5 移动端优先、无支付线下交易
- [ ] 扩展预留：RBAC 两种角色、闲置置换/公益捐赠/教材专区模块预留、AI 审核独立接入点

## B. 数据库设计与初始化（Task 2，spec 3.2）
- [ ] 11 张表齐全且字段与 spec 3.2 一致：user/certification/category/goods/want_buy/comment/conversation/message/order/report/audit_log
- [ ] 枚举值正确：新旧程度 4 级、交易方式 3 种、商品状态 5 种、订单状态 4 种、举报目标 4 种
- [ ] 索引建立：goods（分类/校区/状态/价格/创建时间）、message（conversation_id+created_at）、order（buyer_id/seller_id/goods_id）
- [ ] order 表含 version 乐观锁字段
- [ ] 建表脚本可重复执行（幂等）；种子数据完整（管理员账号、默认分类、校区与成色枚举）
- [ ] user 表仅存密码哈希，无明文密码列（AC-13 前置）

## C. API 接口设计（Task 3，spec 3.1/3.3~3.11）
- [ ] 接口文档（docs/api.md）覆盖 11 个模块全部接口：方法/路径/参数/请求体/响应示例
- [ ] 统一约定落地：`{code,message,data}`、分页 page/pageSize ≤50、时间东八区
- [ ] 错误码表定义：400/401/403/404/409/429/500 对应业务场景
- [ ] 鉴权矩阵定义：公开/登录/发布者本人/会话参与者/订单参与方/管理员
- [ ] 限流策略定义：登录/发布/留言/发消息 10 次/分钟 → 429
- [ ] 文档作为前后端并行开发契约，覆盖全部边界条件场景

## D. 用户与认证（Task 5，spec 2.1/3.3，故事 1-5）
- [ ] 注册（学号唯一校验）/登录（JWT）/退出（黑名单）可用，错误提示明确中文
- [ ] 修改密码需验证原密码；个人资料可查看/修改；他人主页学号打码脱敏
- [ ] 实名认证：提交→管理员审核（通过/驳回+理由）→状态回显；重复提交 409；驳回后可重新提交
- [ ] 禁用账号登录被拒并提示联系管理员（边界 5.1）

## E. 商品发布管理（Task 6，spec 2.2/3.4，故事 6-8）
- [ ] 全字段发布：标题、价格、分类、新旧程度、校区、交易方式、图文描述、图片 ≤9 张且单张 ≤5MB
- [ ] 修改/删除/上下架/标记已售出仅限发布者，他人操作返回 403 且数据不变
- [ ] 必填项校验完整、防重复提交仅创建一条、改动重置待审核、删除不影响既有订单
- [ ] 图片上传：格式/大小校验、重命名存储、弱网重试幂等返回同一 URL

## F. 搜索筛选与分类（Task 7，spec 2.4/3.5，故事 11-13）
- [ ] 分类/价格区间/校区/新旧程度组合筛选准确；关键词命中标题或描述；时间倒序 + 可选价格排序
- [ ] 分页 total/page/pageSize 正确，页码越界返回空列表不报 500
- [ ] 分类管理：公开列表、管理员增改停删；被引用分类删除返回 409

## G. 求购管理（Task 8，spec 2.3/3.6，故事 9、15）
- [ ] 求购发布（物品名称、预算、期望成色）→广场列表（时间倒序）→修改/关闭/删除仅限本人
- [ ] 卖家接单：本人接单被拦截、已关闭求购返回 409、自动创建会话并通知求购者

## H. 互动模块（Task 9，spec 2.5/3.7，故事 8、10、14、16）
- [ ] 留言：发表/分页正序展示/删除（本人或管理员）；已下架商品禁新留言且历史留言隐藏
- [ ] 私聊：会话创建/复用、列表按最新消息排序含未读数、聊天记录分页、仅参与者可读写（非参与者 403）
- [ ] 向禁用用户发送消息失败并提示；新消息可见延迟 ≤3s

## I. 订单模块（Task 10，spec 2.5/3.8，故事 16-17）
- [ ] 创建订单关联商品/求购，初始"待沟通"；对已售出/下架/待审核商品下单返回 409；同商品进行中订单去重
- [ ] 状态机：待沟通→待交易→已完成；未完成可取消；非法流转返回 409；乐观锁并发仅生效一次
- [ ] 订单列表区分"我买到的/我卖出的"并支持状态筛选；完成后商品标记已售出

## J. 平台管理（Task 11，spec 2.6/3.10，故事 18-22）
- [ ] 普通学生访问 `/admin/**` 一律返回 403
- [ ] 商品审核：待审核列表、通过/驳回+理由、驳回后修改重新提交闭环
- [ ] 举报：提交（目标类型/ID/理由/证据图片）→管理员处理（下架商品/封禁用户/删除留言/驳回）；重复待处理举报去重；处理结果留痕
- [ ] 用户禁用/启用：禁用联动下架其待审核与在售商品
- [ ] 分类管理与平台统计可用

## K. AI 智能审核扩展（Task 12，spec 2.7/3.11，故事 23，可选）
- [ ] 敏感词通道接入发布/留言/私聊，"拒绝"时拦截并提示，审核日志落库
- [ ] 外部 AI 接口预留（通过/疑似违规/拒绝），疑似违规进入人工复核队列；可开关且不影响主流程

## L. 验收标准（Task 13.2，spec 第 4 节 AC-01 ~ AC-16 逐条）
- [ ] AC-01~AC-10：功能验收全部通过（注册/认证/商品/筛选/分页/求购/互动/订单/管理端）
- [ ] AC-11：核心接口 P95 ≤ 800ms
- [ ] AC-12：500 并发在线用户错误率 < 0.1%
- [ ] AC-13：数据库明文密码出现次数为 0
- [ ] AC-14：水平/垂直越权拦截率 100%
- [ ] AC-15：常见 SQL 注入、XSS 用例全部被防御
- [ ] AC-16：AI 审核准确率 ≥ 90%、误杀率 ≤ 5%（若启用）

## M. 边界条件（Task 13.1，spec 第 5 节 5.1 ~ 5.9 逐组）
- [ ] 5.1 注册与登录：学号重复、密码规则、禁用登录、Token 失效 401
- [ ] 5.2 实名认证：重复提交 409、材料格式/大小、驳回重提
- [ ] 5.3 商品：字段校验、图片超限/中断、防重复提交、驳回重提、删除保留订单
- [ ] 5.4 搜索：空关键词、注入字符参数化、min>max 返回 400、页码越界空列表
- [ ] 5.5 求购：本人接单拦截、预算非法、已关闭接单 409
- [ ] 5.6 互动：空/超长/敏感词留言、下架商品禁言、非参与者 403、向禁用用户发送失败
- [ ] 5.7 订单：非法对象下单 409、重复下单拦截、取消已完成 409、并发乐观锁、过去时间提示
- [ ] 5.8 举报与管理：重复举报去重、理由校验、分类引用 409、禁用联动下架、处理留痕
- [ ] 5.9 通用：统一错误页/重试、幂等上传、限流 429、请求体过大/非法 JSON 400

## N. 非功能性需求（Task 1/13，spec 第 6 节）
- [ ] 性能：必要索引建立、列表缩略图/CDN、1 万级数据列表 ≤1s
- [ ] 安全：HTTPS、bcrypt/argon2 加盐、参数化查询、XSS/CSRF 防护、敏感操作审计日志、学号脱敏、接口限流、上传文件禁执行权限
- [ ] 兼容：iOS/Android 主流机型、微信内置浏览器、Chrome/Safari 核心流程可用（Task 13.3 真机走查）
- [ ] 可用性：核心功能 ≥ 99.5%，异常均有友好中文提示、无堆栈裸露
- [ ] 扩展：RBAC 结构预留、闲置置换/公益捐赠/教材专区模块预留、AI 通道可开关可替换
- [ ] 数据：每日备份、逻辑删除可追溯、审核日志保留 ≥ 180 天
