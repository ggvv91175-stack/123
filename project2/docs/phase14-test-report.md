## 三、本阶段修复的 BUG

| # | 问题 | 根因 | 修复 | 影响面 |
|---|---|---|---|---|
| 1 | 商品详情页"联系卖家"跳转 `/chat/undefined` | `POST /chat/sessions` 返回 `{...session, reused}`（字段名 `id`），与契约及前端期望的 `conversationId` 不一致；求购接单接口返回 `conversationId`，两接口结构不统一 | [chat.service.ts](../server/src/modules/chat/chat.service.ts#L55-L75) 三个返回点统一改为 `{ conversationId, reused }` | 商品私聊入口（核心链路），修复后浏览器实测跳转 `/chat/7` 正常 |

## 四、体验优化项

| # | 优化 | 位置 | 说明 |
|---|---|---|---|
| 1 | WebSocket 断连重连补强 | [ws.ts](../campus-xianyu-ui/src/utils/ws.ts) | ① auth 改函数形式，每次（重）连动态取最新 token，避免 token 刷新/吊销后重连持旧快照；② 新增断线提示（"正在重连…"）、重连恢复提示、重连耗尽提示（"请刷新页面"）；③ 区分主动断开（登出/401）不弹提示 |
| 2 | WS 发送降级 | ChatView（阶段12 已有，本阶段确认） | WS 未连接时发送自动降级 REST 通道，消息不丢失 |

## 五、防护与兜底覆盖核查

| 项 | 覆盖情况 |
|---|---|
| 表单防重复提交 | 全部提交按钮带 `:loading`（登录/注册/发布商品/发布求购/实名提交/留言/回复/下单/举报/订单操作/接单/后台审核与处理等 20+ 处），代码层另有 `submitting` 标志拦截 |
| 空页面 | `EmptyState` 组件覆盖 19 个页面（列表空、详情不存在、会话未选中等场景） |
| 错误兜底 | http 响应拦截器统一处理 401（清登录态跳登录）/403/404/409/5xx，页面无需重复处理；订单详情等页有"不存在或无权限"兜底态 |
| 图片上传 | 前端 `ImageUpload` 校验类型（jpg/png/webp）+ 大小（≤5MB）；后端内容级校验（伪装文件返回 400「文件内容与图片格式不符」），实测通过 |
| 权限拦截 | 学生访问管理员接口 403、未登录 401、管理员账号不可被禁用（前端隐藏按钮+后端拦截） |

## 六、样式统一与移动端适配

- 公共样式类 `page-card` / `page-title` 在 [global.css](../campus-xianyu-ui/src/styles/global.css) 定义，15 个前台页面 38 处复用；后台页面统一 `el-card + space-y-4` + `AdminLayout`（侧边菜单 + 顶栏）
- 移动端适配（Tailwind 断点）：`FrontLayout` 导航 `sm:hidden`/`sm:flex` 桌面/移动切换；`ChatView` 会话列表与聊天窗口 `hidden md:flex` 移动端互斥；`GoodsDetailView` `md:grid-cols-2` PC 双栏/移动单栏；`GoodsListView` `grid-cols-2 sm:grid-cols-3 lg:grid-cols-4` 响应式网格；后台表格横向滚动列 `fixed="right"` 操作列
- 浏览器工具不支持 375px 视口模拟，移动端适配结论基于源码审查；响应式断点齐全，未发现硬编码溢出宽度
